# Приложение для анализа транзакций "ПроТаблица".

#### В данном проекте представлена backend-составляющая сервиса онлайн-банкинга.
#### Приложение анализирует транзакции, которые находятся в Excel-файле. Разделено функционально
#### на 3 раздела: "Веб-страницы", "Сервисы", "Отчеты". Приложение генерирует JSON-данные для
#### веб-страниц, формирует Excel-отчеты, а также предоставляет другие сервисы.


### Цель проекта:
#### подготовить на бэкенде для онлайн банкинга компоненты для генерирования статистики по определенным
#### критериям пользователя, формирования отчетов и мониторинга расходов.

### <ins>Модуль main.py</ins>

### Функция **main** инициирует работу приложения и предоставляет простой интерфейс для взаимодействия с пользователем.
Осуществляет формирование базового файла транзакций для последующей работы со статистикой.


### <ins>Модуль reports.py</ins>
Содержит функции для формирования различных отчетов

### Функция-декоратор **writing_to_file**.
Используется в разделе "Отчеты" для записи сформированных отчетов в файл в директории **/output_data**.

#### Пример работы функции:

```
Записываю отчёт в output_data/ ...
Отчёт создан
```

### Функция **spending_by_workday**.
Формирует отчет по средним тратам клиента в рабочий/выходной день за 3 месяца.


### <ins>Модуль services.py</ins>
Этот модуль содержит функции поиска по кэшбэку, простому поиску, по телефонным номерам и др.

Функция находит в списке транзакций переводы физическим лицам и выводит эти переводы в виде JSON-строки.

### <ins>Модуль utils.py</ins>

Включает в себя служебные функции-утилиты для создания базового датафрейма с валидными
данными по транзакциям, для выборки транзакций по диапазону дат, для получения данных
о тратах и поступлениях, для получения курса валют и акций и др.
Перечислим лишь основные.


### Функция **get_frame_operations**.
Возвращает отфильтрованные данные всех расходов и поступлений по данным о
транзакциях клиента. Некоторые данные урезаются на данном этапе, но это может
быть изменено в будущем. Добавляются значения по транзакциям в рублёвом эквиваленте,
если операции проводились в валюте.


### Функция **get_span_operations**.
Возвращает данные по транзакциям клиента за указанный диапазон дат. В зависимости
от выбора пользователя выборка данных производится по четырем диапазонам от указанной
даты: "W" - неделя, "M" - месяц, "Y" - год, "ALL" - все транзакции до указанной даты.


### Функция **get_frame_expenses**.
Возвращает данные о сумме трат всего и по категориям за определенный период времени.
Выходно тип данных - словарь. По ходу работы функции дробные числа округляются до
целых. В этом выводе представлены также траты наличными и переводы.


### Функция **get_frame_income**.
Возвращает данные о сумме поступлений всего и по категориям за определенный период
времени: аналогично **get_frame_expenses**, только используются транзакции прихода
средств.


### Функция **get_currency_stock_prices**.
Данныя функция предоставляет данные о курсах валют и акций в виде словаря. Для этой
функции используется файл настроек пользователя **user_settings.json**, находящийся
в корне проекта. Данные по валютам и акциям представлены в виде дробных чисел с
точкой округлённых до двух знаков после запятой. Функция использует API.

### <ins>Модуль views.py</ins>

Данный модуль позволяет собрать воедино функциональности отдельных функций из
**utils.py** для формирования финальных JSON-строк для отображения статистики раздела
"Веб-страницы".


### Функция **aggregate_json**

Возвращает JSON-строку с данными по категориям для трат и пополнений, а также курсы
валют и акций.

## II. Установка <a name="ii-установка"></a>

#### *1. Клонируйте репозиторий:*

```
git clone https://github.com/jaineut-deep/home_work_10-1.git
```

#### *2. Установите Poetry (рекомендуется):*

- Зайдите на сайт https://python-poetry.org/ и перейдите в раздел Documentation
—> Introduction —> Installation.


- Здесь вы найдете команды для установки Poetry (в данном примере указаны для Ubuntu).
Выполните в терминале:
```
sudo curl -sSL https://install.python-poetry.org/ | python3 -
```
- Запустится установка Poetry.
Более подробно про установку Poetry см. на
[сайте](https://python-poetry.org/docs/#installing-with-the-official-installer) проекта.


#### *3. Установите зависимости:*

```
poetry install
```

Эта команда автоматически установит все зависимости, которые перечислены в разделе
**[tool.poetry.dependencies]** и в любых других определенных группах зависимостей
в файле **pyproject.toml**.

## III. Тестирование <a name="iii-тестирование"></a>

!!!Важно!!! Перед тем как начать тестирование нужно сформировать актуальный базовый
xlsx-файл!!!
Для этого:
1. Запустите **main()** из main.py

2. В меню программы выберите пункт "0"

После этого необходимый файл с данными будет сформирован для удобства тестирования.


Чтобы протестировать модули проекта в PyCharm необходимо установить фреймворк pytest:
```
poetry add --group dev pytest
```

В папке **tests** находятся тестовые файлы, которые можно запустить простой командой:
```
pytest
```
